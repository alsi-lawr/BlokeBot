# BlokeBot v0.18.0-rc.1

This is a prerelease candidate for v0.18, not a stable release.

## Experimental dashboard builder

Build named channel dashboards with automation buttons, live values, countdowns,
polls, predictions, giveaways and guessing controls. Control and Editor are separate,
with shared widgets across saved desktop and phone arrangements. Custom dashboards
are experimental; established BlokeBot features are not being relabelled experimental.

## Automation highlights

- Typed command and Manual Run inputs, plus viewer-owned countdowns.
- Explicit cancellation of unfinished runs and opt-in run admission limits.
- Reviewed subflow changes with targeted caller repair, clearer run traces and
  source-readiness feedback.
- Improved schedules with recent skip history, touch canvas gestures, and an
  executable typed timer recipe in the guide.

## Fixes and upgrade notes

- Fixed login navigation returning HTTP 403 when opening Twitch sign-in links.
- Includes database migrations for SQLite and PostgreSQL. Keep a pre-upgrade
  backup; returning to an older version may require restoring it.
